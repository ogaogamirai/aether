# 現存する王族・皇族 一覧と意味・意義（実例付き）

**作成:** 2026-07-11  
**時点:** おおむね 2026 年前半の公開情報に基づく（君主名・継承は変動しうる）  
**範囲:** 主に**主権国家の君主制**（約43か国）。地方・伝統首長は補足。  
**性質:** 調査整理。法的助言ではない。

---

## 0. 読み方

| 用語 | 意味 |
|------|------|
| **皇族・皇室** | 天皇・皇帝系。現存の「皇帝」称号は実質的に**日本**が突出 |
| **王族・王室** | 国王・女王・大公・公・スルタン・首長（アミール）など |
| **儀礼的／立憲** | 実権は議会・内閣。君主は象徴・統合 |
| **執行的／半立憲** | 君主が任命・拒否・軍・宗教などで強い権限を持つ |
| **絶対** | 君主（または王家）が統治の中心 |
| **王族／皇族の意義** | 継承プール、儀礼分担、歴史の身体化、統合・外交の顔 |

**世界像（2026頃）:** 君主を元首とする主権国家は約 **43**。  
そのうち **15** はチャールズ3世を共通君主とする英連邦王国（Commonwealth realms）。

## 1. 王族・皇族の共通の意味・意義（実例つき）

| 意義 | 説明 | 実例 |
|------|------|------|
| **国家統合の象徴** | 言語・地域・党派を超える「国の顔」 | ベルギー王室（言語共同体の緊張の上の統合）、日本皇室 |
| **時間の連続** | 政権交代を超えて国家の時間を繋ぐ | デンマーク・ノルウェー・スウェーデンの長い王室史、日本の皇統連続 |
| **継承の人的プール** | 次世代の君主候補と近親 | 英国ウィンザー家、サウジのアル・サウード家（大家族） |
| **儀礼・外交** | 即位・訪問・親善・災害慰問 | オランダ・スペイン王室の外交、日本の皇室外交 |
| **宗教・伝統の結節** | 国教・慣習法・祭祀と結びつく | タイ国王、モロッコ国王（信者の司令官）、バチカン教皇 |
| **ソフトパワー** | 観光・メディア・国家ブランド | 英国王室、ブータン・ワンチュク家 |
| **立憲の安定装置** | 政治の外に中立の元首を置く | 北欧・日本・英連邦王国 |
| **統治の中枢**（絶対・執行型） | 王家が政策・資源配分の中心 | サウジ、ブルネイ、オマーン、エスワティニ |

## 3. 一覧 A — 日本（皇族／皇室）

| 項目 | 内容 |
|------|------|
| **国** | 日本国 |
| **家** | 皇室（Imperial House of Japan） |
| **君主** | 天皇・徳仁（Naruhito、2019–） |
| **類型** | 象徴・儀礼的（憲法上、国政権能なし） |
| **継承** | 皇室典範：皇統に属する**男系の男子** |
| **皇族の実例** | 皇后雅子、上皇ご夫妻、秋篠宮家（文仁親王・紀子妃・悠仁親王・佳子内親王）、愛子内親王、常陸宮家、三笠宮系・高円宮系の女性皇族 等 |
| **意味・意義** | 世界最古級の世襲連続の体現。国民統合の象徴。祭祀・文化・外交。皇族は継承プールと公的活動の分担 |
| **特記** | 現存で「天皇／Emperor」系が国家元首級として最も明確な例。皇族数減少と継承が現代の中心課題 |

## 10. 実例で見る「王族／皇族の役割」パターン

### パターン1 — 象徴ネットワーク型（日本・北欧・英国）

- **誰:** 君主＋配偶者＋子＋兄弟姉妹家  
- **何をする:** 式典、地方訪問、慈善、外交レセプション  
- **意義:** 民主主義国家の中立的な顔。継承は法律で厳密  
- **実例:** スウェーデン・ヴィクトリア皇太子の公的活動、日本の宮家の地方行事

### パターン2 — 統治エリート型（湾岸・ブルネイ）

- **誰:** 大家系の王子・傍系が閣僚・知事・軍幹部  
- **何をする:** 実際の政策・資源配分  
- **意義:** 王家＝国家経営の中核  
- **実例:** サウジの王族閣僚、カタール首長家の外交戦略

### パターン3 — 連邦の部品型（マレーシア・UAE）

- **誰:** 複数の世襲家  
- **何をする:** 州／首長国を率い、輪番または協議で連邦元首を出す  
- **意義:** 多元的伝統を連邦に埋め込む  
- **実例:** マレーシア9人の统治者会議、UAE最高評議会

### パターン4 — 共通王冠型（英連邦王国）

- **誰:** 実体王室は英国。各国は総督  
- **意義:** 独立主権と歴史的連続の両立  
- **実例:** カナダ総督が国王の代理として議会開会

### パターン5 — 宗教君主型（バチカン、一部モロッコ・タイの要素）

- **意義:** 聖と俗の結節。世襲とは限らない  
- **実例:** 教皇選挙、モロッコ国王の宗教的称号

## 12. 規模感の実例（イメージ）

| 家 | おおよその性格 |
|----|----------------|
| 日本皇室 | **少数精鋭**（戦後縮小）。継承・活動の両面で人数が論点 |
| 英国ウィンザー | 中規模。メディア露出大。傍系の称号整理が進む |
| 北欧王室 | 比較的コンパクト。日常的親しみ |
| サウジ・アル・サウード | **巨大氏族**。統治に必要な人数を王族が供給 |
| マレーシア | **複数王室の連合** |

人数そのものが、その国における「王族の意義」（儀礼か統治か）を映す。

## 14. 廃止・非主権だが「元王族」として残る例（参考）

主権は失っても家名が続く例（現存「王家の末裔」）：

- フランスの旧王家系統、ドイツ・イタリアの旧諸侯、ロシア・ロマノフ系、韓国の旧皇室関係者 等  

**意義:** 国家元首ではないが、文化・観光・民間外交・歴史記憶の担い手になることがある。本一覧の主対象（主権君主制）とは区別する。

## 15. 日本の議論への接続

| 比較から見えること | 内容 |
|--------------------|------|
| 皇族が少ない国 | 日本は継承・活動の両面で「人数」が致命的テーマになりやすい |
| 性別中立の王室 | 北欧・蘭・白・西・英など。持続と平等の両立例 |
| 大家族で統治する王室 | 湾岸型。日本の象徴天皇制とは役割が根本的に異なる |
| 連続のブランド | 日本は「最古級」を国際的に語られやすい。皇族はその連続の現在形 |

## 17. 一行まとめ

> 現存する王族・皇族は、国によって「象徴のネットワーク」「統治エリート」「連邦の部品」「共通の王冠」「宗教元首」と形が違う。  
> 共通しているのは、**国家の連続と統合を、家系という形で社会に示す**ことである。  
> そのなかで日本の皇族は、**世界最古級の世襲連続を、権力なき象徴として担う**稀有な位置にある。
